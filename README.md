# La Peli 🎬

Aplicación web para descubrir películas en cartelera, próximos estrenos y búsqueda por género o título. Datos en vivo desde [The Movie Database (TMDB)](https://www.themoviedb.org/).

## Construido con 🛠️

* React
* TypeScript
* Parcel
* Tailwind CSS
* Axios
* Formik
* Yup

## Despliegue 📦

* GitHub Pages
